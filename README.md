# Dotfiles

This repository contains my personal dotfiles, system configurations, and supporting infrastructure for development and homelab environments.

### Nix / NixOS
- `nix/`
  - `dsk/` — Desktop NixOS configuration
  - `lab/` — homelab server Determinate NixOS configuration
  - `mac/` — macOS (nix-darwin) configuration
  - `flakes/`
    - `neovim/` — Neovim flake
    - `ansible/` — Ansible flake

## Deprecated Components

The following are kept for reference only and are no longer used:

- `.bashrc`
- `.zshrc`
- `.config/tmux/`
- `.config/kitty/`
- `docker/`
- `scripts/wireguard.pl`
